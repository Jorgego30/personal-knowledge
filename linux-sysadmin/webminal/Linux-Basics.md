### Lab4-Lab6
	- `ps:` Displays currently processes.
	- `&:` Sends a process to the background.
	- `kill:` Kills a process.
	- `killall:` Kills all processes with the same name.
	- `pidof:` Gives you the PID of the process.
	- `nice:` Assigns CPU priority before start the process.
		- `19:` Minimum priority.
		- `0:` Default priority.
		- `20:` Maximum priority.
	- `renice:` Reassigns CPU priority start the process.
	- `pstree:` Displays a tree of processes.
		- `-p:` Displays PID's procceses.
	- `wc:` Counts words and lines of a file.
	- `chgrp:` Changes group propietaries of files.
