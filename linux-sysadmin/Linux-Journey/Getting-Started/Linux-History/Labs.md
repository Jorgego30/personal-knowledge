### Getting Started with Linux:
	- `echo:` Prints messages in the shell.
	- `date:` Displays the current date and time.
	- `cal:` Displays the current month's calendar. -> If you add a year, it displays the calendar for that entire year.
	- `expr:` Evaluates a simple math expression. -> If you don't separate the terms with spaces, the shell will print the literal expression.
	- `figlet:` Transforms text into ASCII art.
	- `clear:` Clears the shell. 
### Your First Linux Lab:
	- `whoami:` Prints the current username in the shell.
	- `id:` Displays the user ID (uid), group ID (gid) and all associated groups (groups). If you add `-un` this command prints only the username.
