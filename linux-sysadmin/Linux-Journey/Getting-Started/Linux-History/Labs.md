### Getting Started with Linux:
	- `echo:` Prints messages in the shell.
	- `date:` Displays current date and time.
	- `cal:` Displays the current month's calendar. -> If you add a year, it display the calendar for that entire year.
	- `expr:` Performs a simple math expression. -> If you don't separate the terms with spaces, the shell will print the literal expression.
	- `figlet:` Transform text into ASCII art.
	- `clear:` Clears the shell.
