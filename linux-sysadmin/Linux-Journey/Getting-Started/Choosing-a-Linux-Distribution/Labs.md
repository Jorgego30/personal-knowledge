## Quick Start with Linux
### Basic files operations:
	- `pwd:` Prints the working directory.
	- `echo ~:` Prints the home directory path.
	- `ls ~:` Lists the content of the home directory.
	- `cd ..:` Returns to the parent directory.
	- `cd ~:` Goes to the home directory.
	- `touch:` Creates a file.
	- `>:` Redirects the output of a command into a file.
	- `mkdir:` Creates a directory.
	- `ls -l:` Lists content with additional details.
	- `cp:` Copies a file.
	- `cp -r:` Copies a directory.
	- `mv:` Renames a file/directory. Move a file to a directory.
	- `rm:` Removes a file.
	- `rm -i:` Adds a confirmation prompt before deleting each file.
	- `rmdir:` Removes an empty directory.
	- `rm -r:` Recursively removes a directory with everything inside it.
	- `-f:` Flag to force an action.
	- `ls -R:` Lists subdirectories recursively.
