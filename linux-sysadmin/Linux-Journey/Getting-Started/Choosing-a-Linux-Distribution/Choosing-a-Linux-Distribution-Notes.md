Operation systems built arond Linu Kernel -> Linux Distributions/Distros.
There isn't single best choice for everyone.
Linux System    -> Hardware -> physical components -> CPU.
										-> Memory.
										->Storage devices.
			-> Linux Kernel -> core of operation system.
			-> User space -> enviroment where user interacts with system.
Linux Distro      -> Complete operation system.
			-> Differents distros has differents philosophy/package managers...
To choose the best Linux Distro it's easier starting with your own needs.
	-> Usually best distro is that one matches your goals.
Updates   -> Stable or point-release distros -> updates are more planned and predictable.
		-> Rolling-release distros -> updates are in continuously updating.
Distros      -> For begginers -> Ubuntu     |
					-> Linux Mint.  | easy to install and have widely documentation.
		-> For developers -> Fedora
					-> Arch
					-> Gentoo
		-> Servers and stability -> Debian
						-> Red Hat Enterprise Linux
