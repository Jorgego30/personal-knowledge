### Bandit labs:
	- You can see the type of shell you have with `echo $SHELL`.
	- You can see it in `passwd` too. It is recommended to filter with `grep`.
	- You can set the shell type from vim with `:set shell=/bin/bash`.
	- You can enter vim from `more` with `v`.
	- You can recover a lost git branch with `git checkout -b <branch> <commit-hash>`.
