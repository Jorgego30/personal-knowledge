## PicoCTF - Warmed Up

- **Category:** General Skills
- **Difficulty:** Easy

### Challenge Description
This challenge gives us number in hexadecimal to transform it to decimal.
### Solution
- To solve this challenge, I used a C script to find the flag.

1. Create a C file with `touch`.
2. Write the script in C, include the `<stdio.h>` library and do a printf with the argument %d to convert the hexadecimal number to decimal.
3. Compile the file with gcc.
4. Execute the file with ./a.out.
- The automated solution is available in solve.sh.
